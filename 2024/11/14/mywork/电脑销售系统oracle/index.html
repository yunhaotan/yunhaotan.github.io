用户表:编号，用户名，密码，邮箱，角色，用户头像；

影院表：编号，影院名称，影院地址；
放映厅表：编号，放映厅名称，放映厅容量，所属影院编号；

本系统包含的数据表如下：

1. 商品表 (goods)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
gID CHAR 主键 6 否 - 商品ID
gNAME VARCHAR2 非空 10 否 - 商品名称
gKIDS VARCHAR2 可空 6 是 - 商品分类ID
gUNIT NUMBER 检查 - 否 - 单位，必须大于0
gPRICE NUMBER 检查 - 否 - 价格，不能小于0

2. 供应商表 (provider)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
pID CHAR 主键 6 否 - 供应商ID
pNAME VARCHAR2 非空 10 否 - 供应商名称
pACC CHAR 可空 19 是 - 账户信息
pADD VARCHAR2 可空 8 是 - 地址

3. 仓库表 (store)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
sID CHAR 主键 6 否 - 仓库ID
sADD VARCHAR2 可空 8 是 - 地址
sLEAD VARCHAR2 可空 4 是 - 联系负责人

4. 门店表 (shop)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
shID CHAR 主键 6 否 - 门店ID
shNAME VARCHAR2 非空 10 否 - 门店名称
shADD VARCHAR2 可空 8 是 - 地址

5. 营业员表 (assistant)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
aID CHAR 主键 6 否 - 营业员ID
aNAME VARCHAR2 非空 4 否 - 营业员姓名
aFEAT NUMBER 可空 - 是 - 业绩特征
shID CHAR 外键 6 是 - 关联的门店ID

6. 管理员表 (manager)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
mID CHAR 主键 6 否 - 管理员ID
mNAME VARCHAR2 非空 4 否 - 管理员姓名
mFEAT NUMBER 可空 - 是 - 管理员特征

7. 采购员表 (shopper)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
shopperID CHAR 主键 6 否 - 采购员ID
shopperNAME VARCHAR2 非空 4 否 - 采购员姓名
shopperFEAT NUMBER 可空 - 是 - 采购员特征

8. 商品库存更新历史表 (goods_history)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
hID NUMBER 主键 - 否 - 历史记录ID
gID CHAR 外键 6 是 - 关联的商品ID
oldQuantity NUMBER 可空 - 是 - 旧数量
newQuantity NUMBER 可空 - 是 - 新数量
changeDate TIMESTAMP - - 否 - 更改日期

9. 销售表 (sales)

列名 数据类型 字段类型 长度 是否为空 默认值 备注
saleID NUMBER 主键 - 否 - 销售记录ID
gID CHAR 外键 6 是 - 关联的商品ID
quantity NUMBER 检查 - 否 - 销售数量，必须大于0
salesPrice NUMBER 检查 - 否 - 售价，不能小于0
aID CHAR 外键 6 是 - 关联的营业员ID
saleDate TIMESTAMP - - 否 DEFAULT SYSTIMESTAMP 销售日期
